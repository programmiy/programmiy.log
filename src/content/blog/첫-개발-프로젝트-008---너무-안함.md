### 테일러 급수란
$$
f(x) = \sum_{n=0}^{\infty} \frac{f^{(n)}(a)}{n!} \cdot (x - a)^n
$$
의 기본 형식으로 나타나는 테일러 급수.
$n=0$일때 $f^0(x) = f(x)$이기 때문에 $f(x)$와 비슷한 다항함수를 찾기 위해 
$$
f(x) = f(a) + f'(a) \cdot (x - a) + \frac{f''(a)}{2!} \cdot (x - a)^2 + \frac{f^{(3)}(a)}{3!} \cdot (x - a)^3 + \cdots
$$
의 형태로 풀어나간다. 

참고로, $f^1(x)= f'(x)$임 ($f^{(n)}$이 뜻하는건 $n$만큼 미분하라는 뜻)
***
### $(x-a)$를 곱해주는 이유

테일러 급수는 함수 𝑓(𝑥)를 다항식으로 근사하려는 방법,
그 근사값을 구할 때 **어떤 점 𝑎**를 기준으로 함수의 미분값들을 사용함.

함수 𝑓(𝑥)가 점 𝑎 근처에서 어떻게 변화하는지를 정확하게 표현하려면 미분을 사용하고, 그 미분값들이 𝑥에 어떻게 영향을 미치는지 설명하기 위해 (𝑥−𝑎)를 곱해줌

$$
f'(a) =\lim\limits_{x \to a} \frac{f(x)-f(a)}{x-a}
$$
이걸 미분계수라 하는데, $(x-a)$는 $x$에서 $a$로 변화한 변화량을 나타내고, 미분계수(=기울기 (변화율)) 와 곱해주면 실제 변화량을 계산할 수 있음
***
### 미분한 $n$횟수만큼 ${n!}$ 팩토리얼로 나눠주는 이유

도함수를 계속 미분하다보면 $f(x)$가 상수 항의 도함수가 되는데, 이렇게 되면 미분할때마다 변화율(기울기)는 낮아지는데 x의 영향을 줄이는 미분을 수행했기에 y의 변화량 또한 유사한 수준으로 내려야하기에 팩토리얼로 나눠준다.
$f(x)$를 미분한다는것은 x에 대한 y의 변화량과도 같은데 
미분을 두번할때부터 $2!$로 나누기 시작하는데 이것은 기울기의 기울기를 구하는 것이기 때문에 미분한 횟수만큼 곱해서 나눠준다고 생각하면 된다.

사실 여기까지 쓰긴했는데 잘 이해가 안감 암튼간에 미분한 n만큼 팩토리얼로 나눠줘야한다만

### 테일러 근사 적용법

![](/programmiy.log/images/uploads/velog/0705a5cf-95ce-4d22-baf3-8c4070919bc9-image.png)

여기서의 I는 $Intensity$, pixel intensity에서 옴 번역어대론 픽셀 강도, 즉 픽셀의 rgb 값을 제외한 grayscale 상 검정~백색으로 구분되는 말그대로의 광도 정보의 값임

강도라고 부르기도 하는데 난 광도라고 할래

움직이는 물체로 표현되는 광도 값 $I(x, y, t)$인 물체를 생각한다면,
시간 $dt$가 지나면 $dx$와 $dy$만큼 이동하게됨
이제 새로운 광도는 $I(x+dx, y+dy, t+dt)$가 되는것
$dt, dx, dy$는 특정 값이 아닌 이론적으로 가능한 미분량 변화량을 추상적으로 나타내는 기호
***
#### 테일러 근사를 적용한다면?

![](/programmiy.log/images/uploads/velog/5a3a1c59-1326-4a7c-a93f-a1bbd187bbe3-image.png)


$\delta x, \delta y, \delta t$는  가장 현실적인 컴퓨터 비전에서 다룰 만한 작은 사이즈의 변화량이라고 가정

즉, 특정 객체의 광도 값을 $I(x, y, t)$ 라고 한다면,
$\delta t$ 이후의 광도 값 $I(x+δx,y+δy,t+δt)$ 을 구하기 위해 위 사진같은 식이 나오게되는데 

이과정이 어떻게 이루어지는지  유도해보고자 한다.



 테일러 근사를 하기 위해 근사 식을 세워보면, 
$$
I(x+\delta x, y+\delta y , t+\delta t) ≈ I(x, y,t)+ \frac{∂I}{∂x}\delta x + \frac{∂I}{∂y}\delta y +\frac{∂I}{∂t}\delta t
$$

(1차근사만 하는 이유는 $\delta x, \delta y, \delta t$가 충분히 작은 변화량이라고 가정을 이미 해둬서 2차항 부터는 0에 근접하는 값이 나오기에 무시가능함 )

광학 흐름은 다음 두 가지 사실을 가정하고 들어간다.

1. 연속된 프레임 사이에서 움직이는 물체의 픽셀 강도(intensity)는 변함이 없다.
2. 이웃하는 픽셀은 비슷한 움직임을 갖는다.

여기서 사실 1을 이용한다면 $I(x, y, t)$와 $I(x+δx,y+δy,t+δt)$는 사실상 같다.

즉 우변항이 0인 위 사진과 같은 식이 나오게된다.

***
#### more one step 


여기서 

$u: x$-방향 속도 (픽셀 이동량/시간 or 프레임) 
$$
\frac{\delta x}{\delta t}$$

$v: y$-방향 속도 (픽셀 이동량/시간 or 프레임)
$$
\frac{\delta y}{\delta t}$$

를 도입하고, 

$$
\frac{∂I}{∂x}\delta x + \frac{∂I}{∂y}\delta y +\frac{∂I}{∂t}\delta t = 0
$$
의 꼴에 대입하면 

$$
\frac{∂I}{∂x}(u*\delta t) + \frac{∂I}{∂y}(v*\delta t) +\frac{∂I}{∂t}\delta t = 0
$$

$\delta t$는 모든 항에 존재하므로 나눠주면 

최종적으로 다음과 같이 나오게 된다.

$$
\frac{∂I}{∂x}u + \frac{∂I}{∂y}v+\frac{∂I}{∂t} = 0
$$

***
### 각 항 설명 

1. $\frac{∂I}{∂x}u:x$방향 밝기 변화율 곱하기 속도

2. $\frac{∂I}{∂y}v: y$방향 밝기 변화율 곱하기 속도
3. $\frac{∂I}{∂t}:$ 시간에 따른 밝기 변화율 
***


## Gunnar Farnebäck(군나르 페너백) 알고리즘     

원리: 두 프레임을 입력받음 > 분석 > 결과 도출

동영상의 경우 두 프레임씩 빼내고 반복문돌리기?로 사용해야 할듯


dense optical flow에서 사용하는 만큼 모든 픽셀을 대상으로 두 프레임 간의 픽셀 강도 변화를 감지하는게 기본 골자 
그 결과는 HSV 색상 형식으로 변환되어 명확하게 시각화된 이미지로 나타남

>Hue(색상) Saturation(채도) Value(명도)



플로우 벡터(픽셀 강도 변화 계산한 것)(이걸 시각화한게 위의 hsv 이미지) 즉, $\frac{\delta x}{\delta t}\rarr u, \frac{\delta y}{\delta t} \rarr v$를 통해 옵티컬 플로우의 광도(픽셀 강도)나 픽셀 이동 방향을 계산 가능   
이후, 플로우의 방향은 **색상(Hue)**으로 나타내고, **플로우의 크기(거리, Magnitude)**는 HSV 색상 표현에서 Value로 나타냄
최적의 가시성을 위해 HSV의 **픽셀 강도(채도)**는 255로 설정 (Magnitude가 높을수록 더 잘 표현되는 효과)

플로우의 크기 계산
> Magnitude= $\sqrt {u^2 +v^2}$

***
### 실용 예시

OpenCV에서는 cv2.calcOpticalFlowFarneback 함수를 제공하여 밀집 옵티컬 플로우를 계산하고 시각화가능 함

```python
cv2.calcOpticalFlowFarneback(prev, next, pyr_scale, levels, winsize, iterations, 
poly_n, poly_sigma, flags[, flow])
```

### 파라미터 설명
1. prev (이전 프레임)
설명: 이전 프레임을 나타내는 이미지, 그레이스케일이여야함
타입: numpy.ndarray
첫 번째 프레임이며  8비트 단일 채널 이미지(입력)

> 8비트인 이유 
8비트 = 1바이트 
1바이트는 2^8개의 데이터를 가지고 있음
그레이 스케일의 보통 범위인 0~255 (256개)를 나타내기 가장 적합
그레이 스케일은 numpy.ndarray의 형태로 출력됨

2. next (다음 프레임)
설명: 분석할  다음 프레임, prev와 마찬가지로 그레이스케일이어야 함
타입: numpy.ndarray
두번째 프레임 8비트 단일 채널 이미지(입력)





3. pyr_scale (피라미드 축소 비율)
설명: 이미지 피라미드를 생성할 때 각 레벨의 축소 비율을 지정하는 값입니다. 이 값은 0과 1 사이의 실수로 설정합니다.
0.5로 설정하면 각 레벨에서 이미지를 반으로 축소합니다.
1로 설정하면 피라미드를 만들지 않고 원본 이미지를 그대로 사용합니다.
기본값: 0.5
타입: float

# https://velog.io/@richpin/Computer-Vision-Image-Filtering-Pt.1 참고해서 수정할예정

4. levels (피라미드 레벨 수)
설명: 이미지 피라미드에서 사용할 레벨의 수입니다. 피라미드는 여러 레벨에서 이미지를 축소하여 계산하는 방식입니다.
높은 값을 설정하면 더 많은 레벨을 통해 더 세밀한 플로우를 계산할 수 있지만, 계산량이 많아집니다.
기본값: 3
타입: int

# https://velog.io/@richpin/Computer-Vision-Image-Filtering-Pt.1 참고해서 수정할예정



5. winsize (윈도우 크기)
설명: 움직임(Optical Flow)을 계산할 때 참조하는 영역의 크기를 결정
이는 픽셀 주변의 이웃 영역을 평균화하는 역할을 하며, 값이 클수록 더 넓은 영역을 고려함 
너무 작으면 이미지 노이즈에 민감하고, 너무 크면 세부적인 움직임이 흐릿해질 수 있음

기본값: 15
타입: int



- 작은 winSize: (저해상도 특화)
작은 영역을 참조함
노이즈에 민감할 수 있으며, 특징점이 정확하게 검출되지 않을 수 있음
처리 속도가 빠를 수 있음

- 큰 winSize: (고해상도 특화)
넓은 영역을 참조함
더 많은 정보(픽셀 값)를 사용하여 정밀한 위치를 계산하므로, 더 정확한 결과를 얻을 수 있음
처리 시간이 길어질 수 있음









6. iterations (반복 횟수)
설명: 가속화된 흐름 계산을 위한 반복 횟수입니다. 알고리즘이 각 픽셀에 대해 반복하면서 옵티컬 플로우를 점진적으로 개선합니다.
높은 값을 사용하면 정확도가 높지만 계산 시간이 길어집니다.
기본값: 3
타입: int





7. poly_n (다항식 근사에 사용할 이웃의 크기)
설명: 다항식 근사에서 사용할 이웃의 크기입니다. 이 값은 픽셀 주변을 다항식으로 근사하는데 사용됩니다.
값이 커질수록 더 많은 이웃 픽셀을 고려하지만, 처리 시간이 길어질 수 있습니다.
기본값: 5
타입: int
8. poly_sigma (다항식 근사를 위한 표준 편차)
설명: 다항식 근사에 사용되는 표준 편차입니다. 값이 커지면 더 넓은 영역의 이웃 픽셀이 고려됩니다.
기본값: 1.1
타입: float
9. flags (플래그)
설명: 계산에 영향을 주는 여러 플래그 값을 설정할 수 있는 파라미터입니다. 대표적인 값은 다음과 같습니다:
cv2.OPTFLOW_USE_INITIAL_FLOW: 초기 흐름을 사용하여 계산을 시작합니다.
cv2.OPTFLOW_FARNEBACK_GAUSSIAN: 가우시안 블러를 적용하여 더 부드러운 결과를 생성합니다.
기본값: 0
타입: int
10. flow (옵션, 결과 플로우)
설명: 결과로 나온 옵티컬 플로우를 저장할 배열입니다. 이 파라미터는 기본적으로 None으로 설정되어 있지만, 미리 할당된 배열을 전달하여 플로우 계산 결과를 받아올 수 있습니다.
타입: numpy.ndarray (옵션)

완성된 텍스트가 아님

### 코드 예시와 실제 구동 


```python
# Importing libraries
import cv2
import numpy as np
# Capturing the video file 0 for videocam else you can provide the url
capture = cv2.VideoCapture("video_file.avi")

# Reading the first frame
_, frame1 = capture.read()
# Convert to gray scale
prvs = cv2.cvtColor(frame1, cv2.COLOR_BGR2GRAY)
# Create mask
hsv_mask = np.zeros_like(frame1)
# Make image saturation to a maximum value
hsv_mask[..., 1] = 255

# Till you scan the video
while(1):
	
	# Capture another frame and convert to gray scale
	_, frame2 = capture.read()
	next = cv2.cvtColor(frame2, cv2.COLOR_BGR2GRAY)

	# Optical flow is now calculated
	flow = cv2.calcOpticalFlowFarneback(prvs, next, None, 0.5, 3, 15, 3, 5, 1.2, 0)
	# Compute magnite and angle of 2D vector
	mag, ang = cv2.cartToPolar(flow[..., 0], flow[..., 1])
	# Set image hue value according to the angle of optical flow
	hsv_mask[..., 0] = ang * 180 / np.pi / 2
	# Set value as per the normalized magnitude of optical flow
	hsv_mask[..., 2] = cv2.normalize(mag, None, 0, 255, cv2.NORM_MINMAX)
	# Convert to rgb
	rgb_representation = cv2.cvtColor(hsv_mask, cv2.COLOR_HSV2BGR)

	cv2.imshow('frame2', rgb_representation)
	kk = cv2.waitKey(20) & 0xff
	# Press 'e' to exit the video
	if kk == ord('e'):
		break
	# Press 's' to save the video
	elif kk == ord('s'):
		cv2.imwrite('Optical_image.png', frame2)
		cv2.imwrite('HSV_converted_image.png', rgb_representation)
	prvs = next

capture.release()
cv2.destroyAllWindows()

```
